# Excalicord+

一款面向课程讲解、方案演示和软件教学的白板录制工具。它保留 Excalicord 式白板与幻灯片工作区，并增加浏览器原生的整屏、窗口、标签页和框选录制。

**在线使用：** [excalicord.learnbox.cc](https://excalicord.learnbox.cc)
**源代码与 Windows 下载：** [goking81/excalicord-plus](https://github.com/goking81/excalicord-plus)

录制、编码和文件保存均在浏览器与用户选择的本地文件夹完成；视频不会上传到本站服务器。

## 能做什么

| 录制场景 | 用途 |
| --- | --- |
| 白板全景 | 讲解知识、绘图、方案梳理 |
| 当前幻灯片 | 逐页课程或演示文稿讲解 |
| 整个屏幕 | 跨网页、跨软件的完整操作演示 |
| 指定窗口 / 浏览器标签页 | 软件功能演示，避免录入无关内容 |
| 框选区域 | 只录需要展示的范围 |

还包括：

- 摄像头画中画：位置、大小、圆形或圆角、镜像；
- 麦克风、系统声音（由浏览器的共享选择器决定是否可用）；
- MP4 优先输出；浏览器不支持时自动使用 WebM；
- 鼠标高亮和点击提示；
- 演示缩放：在录制时放大网页或软件中的小字；
- 白板画幅：16:9、9:16、1:1 等；只影响白板和幻灯片，不会裁切整屏或窗口录制；
- 保存时选择本地文件夹；不要求在开始录制前先选目录。

## 在线版怎么用

推荐使用桌面版 Chrome 或 Edge，打开 [excalicord.learnbox.cc](https://excalicord.learnbox.cc)。

1. 在白板上绘制，或用右侧“幻灯片”栏新增页面。
2. 右上角点击“设置”，配置摄像头、麦克风、画幅和鼠标效果。
3. 点击“录制”后，首次会先要求选择本次录制的本地保存文件夹。
4. 选择“录白板全景”“录当前幻灯片”或“录屏幕 / 窗口 / 标签页”。只有录屏幕或软件时，浏览器才会弹出系统共享选择器。
5. 停止录制后会留在白板页面，视频自动保存到先前选择的文件夹；如启用了摄像头画中画，点击“保存合成视频”即可生成最终视频。

### 整个屏幕录制

默认全画面录制“整个屏幕”时，Excalicord+ 会直接保存浏览器提供的屏幕视频流。开始后可以切换到其他网页或软件，视频会持续跟随屏幕，不会停在 Excalicord 页面。

若手动框选区域或开启演示缩放，则需要网页实时合成画面。纯网页浏览器在这种情况下会降低后台标签页的运行频率，所以请让 Excalicord+ 页面保持运行。

### 白板翻页

选择“录当前幻灯片”或“录白板全景”后，可在录制中直接按键盘 `←` / `→` 切换上一页或下一页。翻页走即时白板视口切换，不会等待动画或打开系统共享窗口。

### 画中画与整屏录制

整屏或窗口录制时，摄像头会被保留为独立素材；停止后使用“保存合成视频”即可叠加为最终画中画。合成期间请保持页面在前台。

## Windows 本地便携版

GitHub Releases 提供 `Excalicord+-Windows-Portable` 压缩包，适合需要保留本地运行环境、调试或在其他 Windows 电脑使用的场景。

1. 下载并解压压缩包到任意文件夹。
2. 双击 `start-excalicord.bat`。
3. 在 Chrome 或 Edge 打开 `http://127.0.0.1:5001/`。

压缩包已经包含便携 Node.js，不会安装软件、不需要管理员权限，也不会修改系统环境变量或注册表。启动时保持黑色窗口开启即可；录制完成后关闭窗口可停止本地服务。

> 首次打开仍需要联网加载 Excalidraw 的浏览器依赖。在线版不需要下载或运行本地服务。

## 浏览器能力边界

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 白板、幻灯片、整屏、窗口和标签页录制 | 支持 | 系统共享选择器由浏览器提供 |
| 保存到本地文件夹 | 支持 | 依赖 Chrome / Edge 的 File System Access API |
| 系统声音 | 视浏览器而定 | 在共享选择器中勾选并不保证一定返回音轨 |
| 摄像头画中画 | 支持 | 整屏 / 窗口录制会在停止后合成 |
| 隐藏任意软件中的鼠标 | 不支持 | 浏览器只能控制共享源提供的鼠标行为 |
| 手机、Safari、Firefox | 不建议 | 屏幕共享、目录保存或编码能力不完整 |

屏幕共享和本地文件夹选择需要 HTTPS，因此在线版必须通过 `https://excalicord.learnbox.cc` 使用；本地版的 `127.0.0.1` 也属于浏览器认可的安全本地地址。

## 开源来源

本项目以 [more-excalicord](https://github.com/bingyunjiang/more-excalicord) 为蓝本，并使用 [Excalidraw](https://github.com/excalidraw/excalidraw) 提供白板能力。Excalicord+ 补充了 Windows、本地便携运行、浏览器整屏/窗口录制、文件夹保存、浏览器端画中画合成，以及 Excalicord 式主界面与幻灯片栏。
